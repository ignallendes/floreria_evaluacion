## Descripción
"Dale tu Sentido” es una vitrina digital inspirada en un emprendimiento real, creada para presentar y ofrecer productos como rosas de jabón, peluches e insumos para la elaboración de rosas artesanales. El proyecto busca brindar una experiencia atractiva y cercana para que los usuarios conozcan y adquieran regalos únicos y personalizados. Su objetivo principal es apoyar la difusión y venta de productos pensados para transmitir emociones y crear momentos especiales
